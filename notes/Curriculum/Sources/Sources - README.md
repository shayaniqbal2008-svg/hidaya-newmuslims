# Sources

Drop PDFs of new-Muslim guides and books here. Claude reads each one and writes a summary note next to it (topic order, what it adds beyond [[Research Report]], in our own words). Lessons never copy text from these files.

> [!note] Where the PDFs actually live
> When you drag a PDF into a note, Obsidian saves the file in `Attachments/` and embeds it. That's fine: the summary notes below link to the files.

## Summaries
- [[Source - The Revealed Path]]: full text read. Good reference for belief and ihsan lessons; misses almost all convert pain points.
- [[Source - The New Muslim Guide (Bahammam)]]: scanned image PDF, unreadable without OCR; same content is on newmuslimguide.com.
- [[Source - The New Muslims Field Guide]]: **gold for pain points** (family letter, burnout, first masjid visit, the few-weeks-in slump).
- [[Source - Welcome to Islam]]: **gold for structure**: a 5-day program; model for our Days 1–7. One prayer advice conflict flagged for scholars.
- [[Source - First Instructions on Worship]]: Hanafi step-by-step prayer and purification; reference for prayer lessons.
- [[Source - Being Muslim a Practical Guide]]: moderate; reference for Phase 2–3 belief and spiritual-growth lessons.
