# T4 · Convert app: build plan and verification

> [!info] What this note is
> The plan for T4 (milestone 4 of the [[Hidaya - Build Prompt|build prompt]]), built from [[T3 - Stack and Data Model]]. Code lives in `~/Projects/new-muslims-program`. Progress is logged on the [[Hidaya|hub]].

## Build steps
1. **Scaffold** Next.js (TypeScript, Tailwind, App Router) + Supabase client, git repo, `.env.example`.
2. **Content compiler** `scripts/compile-lessons.ts`: vault `Lessons/` → `content/lessons/*.json`; [[Citation Bank]] + source datasets → `content/citations.json` (full Arabic and English, never generated); [[Glossary]] → `content/glossary.json`. Runs `check_lessons.py` first and stops on any error.
3. **Database:** migrations for the 19 tables in T3 §3.2, RLS for the 6 rules in §3.3, the `dashboard_converts` view.
4. **Scheduling:** the "today's lesson" pure function (Days 1–3 together, one a day after, calendar modules, Ramadan join, welcome-back gaps, timezones).
5. **Lesson player:** all 16 screen types, madhab variants, teen lines, placeholders, `[SCHOLAR]` stripping, draft badge, glossary taps, Other-schools and Sources cards, spaced review at the end.
6. **Sign-up:** `/join/<code>` → email 6-digit code → profile (first name, birth year, consent choices, discreet mode on) → Days 1–3.
7. **Convert screens:** Today, Path (progress), Lesson, Guide, Settings (reminders, discreet mode, quick exit, export, delete).
8. **Reminders:** web push (VAPID) + email (Resend) via a 15-minute cron route; neutral text.
9. **AI guide:** crisis check (Haiku 4.5) → prompt (Spec §6.2 rules + lesson context + Citation Bank retrieval, profile as quoted data) → model behind `GUIDE_MODEL` → output check on citations → "Ask my imam" with confirm-before-send.
10. **Red-team set** (≥150 questions) + eval runner. Running it costs API money, so Shayan says go first.
11. **PWA:** manifest, service worker, add-to-home-screen walkthrough. **README** for Shayan.

### Decisions made while building (and why)
- **Replies from the guide aren't streamed.** The scripture check has to pass before anything is shown; a streamed reply can't be taken back. A few seconds' wait is the cost.
- **Reminders run from Supabase Cron** every 15 minutes, because Vercel's free plan only runs cron jobs once a day.
- **App name "Daily" with a dawn icon**, and a plain front page, so nothing on a shared phone gives the convert away.
- **Minors counted from birth year conservatively**: anyone who could still be 17 this year.
- **The gender question at sign-up is optional** and only helps the guide; lessons still name both men's and women's positions (hiding one is a later feature).
- Added crisis lines for under-18s (Teen Line text TEEN to 839863; Childhelp 1-800-422-4453) next to 988, the DV hotline and 911.
